# 需求：直播 v2 取流（#49）與本機時移（#51）

## 目標

直播改用 v2 `getRoomPlayInfo` 取得多線路與 HLS。使用者可選擇開啟「直播時移」：App 在本機暫存直播片段，可倒退、快轉、回到 LIVE，類似 YouTube 直播。

## 實測（2026-11-12，熱門直播間）

- v2 回傳 `http_stream flv`、`http_hls ts`、`http_hls fmp4`，每種都有 `avc`、`hevc`，各 2 個 `url_info` host。未登入時 `current_qn=250`，`accept_qn=[10000,400,250]`；`g_qn_desc` 為畫質名稱表。
- fmp4 m3u8：`#EXT-X-VERSION:7`、`#EXT-X-TARGETDURATION:1`、`#EXT-X-MAP:URI="h<id>.m4s"`，每個片段 1 秒，**播放清單只保留 8 個片段**，片段是相對路徑（`<seq>.m4s`），不需要 Referer 或 query 就能下載。250 畫質每個片段約 190KB。
- 結論：遠端沒有回看能力，時移必須由 App 自己錄。

## 驗收條件

### #49 v2 取流
- AC-1：直播改用 v2 `getRoomPlayInfo`，v2 失敗時退回 v1 `playUrl`。
- AC-2：線路按鈕列出 v2 回傳的多個 CDN host，可以切換。
- AC-3：畫質清單來自 `accept_qn` 與 `g_qn_desc`，切換後帶新的 qn 重新取流。
- AC-4：時移關閉時，播放行為與現在相同（自動重連、暫停後回到最新畫面）。

### #51 時移
- AC-5：設定 → 播放設定新增「直播時移」：關閉／5 分鐘／10 分鐘／30 分鐘，預設關閉，用次級選單選擇。低記憶體裝置最多 5 分鐘；記憶體 critical 時不啟用。
- AC-6：開啟時，直播改播本機暫存。進度條顯示已暫存範圍與目前位置；落後直播時顯示「-mm:ss」，LIVE 標記變灰。
- AC-7：控制列隱藏時，按左右鍵倒退／快轉 10 秒，並顯示控制列。不能早於暫存起點，也不能超過直播最新位置。
- AC-8：進度條可以取得焦點（從按鈕列按上鍵）。焦點在進度條上時，左右鍵倒退／快轉 10 秒，OK 鍵回到 LIVE。
- AC-9：時移開啟時，暫停後繼續會從暫停的位置接著播；暫停期間持續錄製。暫停超過保留長度時，從最舊的暫存位置開始播。
- AC-10：暫存超過設定長度時，刪除最舊的片段，播放不中斷。
- AC-11：離開直播畫面時刪除暫存檔；App 啟動時清掉上次殘留的暫存。
- AC-12：遠端網址過期或錄製連續失敗時，自動重新取流並繼續錄製；中斷的地方插入 discontinuity，播放不會卡死。
- AC-13：切換畫質或線路會清除暫存，從新的串流重新開始。

## 不做的範圍

- 不接 BTR 多 CDN 分段下載（評估結果：遠端片段只有 1 秒，多 CDN 平行的效益小，之後再議）。
- 不錄 FLV；時移只用 HLS fmp4。
- 不保存到 App 結束後，也不做回放下載。

## 限制

- 本機 server 只綁 loopback。
- 不改 `packages/video_player_android` 的 pigeon 介面（只用 Dart 端 `seekTo`、`position`）。
- 介面文字只用繁體中文；`flutter analyze` 不能新增問題。
- 使用者已要求直接做。
