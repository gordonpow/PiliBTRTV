Android TV 版第三方 B站用戶端，基於 BiliTV，加上「線程撕裂者」（BTR）多 CDN 播放加速。

## 下載哪一個？
- `PiliBTRTV-v1.2.2-btr.13-arm64-v8a.apk`：64 位元，大多數較新的電視盒和電視用這個。
- `PiliBTRTV-v1.2.2-btr.13-armeabi-v7a.apk`：32 位元，給較舊或 32 位元系統的電視。64 位元版裝不上時，改用這個。
- 從 App 內更新時，會自動選擇符合裝置的版本。

## 修正
- **4K 60 幀從首頁卡片開播時仍然卡頓**：
  - 原因：從卡片按 OK 開播時，App 直接沿用卡片預覽的播放器。這個播放器一定用「相容」畫面模式，所以就算設定為「原生」，隧道播放也不會生效。
  - 現在「播放畫面模式」設為「原生」時，按 OK 會改用原生畫面重新準備播放，隧道播放可以正常生效。
- **部分電視播直式影片時，畫面旁邊出現綠色色塊**：同樣的原因，一起修正。

## 4K 60 幀仍然卡頓時
- 到「設定 → 播放設定」，把「播放畫面模式」設為「原生」，並開啟「隧道播放（實驗）」。
- 播放同一部 4K 60 幀影片後送出錯誤報告。報告中應該會顯示「隧道播放 設定=開 實際=隧道模式」。

## 已知影響
- 「原生」畫面模式下，從卡片按 OK 開播會比之前慢約 1 秒。「相容」模式不受影響。

## 注意
- APK 使用與 btr.6 以前相同的金鑰簽署，可以直接覆蓋安裝。
- 64 位元版的版本號比較大。電視裝過 64 位元版之後，若要改裝 32 位元版，要先解除安裝。
