Android TV 版第三方 B站用戶端，基於 BiliTV，加上「線程撕裂者」（BTR）多 CDN 播放加速。

## 下載哪一個？
- `PiliBTRTV-v1.2.2-btr.11-arm64-v8a.apk`：64 位元，大多數較新的電視盒／電視。
- `PiliBTRTV-v1.2.2-btr.11-armeabi-v7a.apk`：32 位元，較舊或 32 位元系統的電視（64 位元版無法安裝時用這個）。
- 從 App 內更新會自動選擇符合裝置的版本。

## 新增
- **移除稍後再看**：「觀看紀錄 → 稍後再看」中按住確定鍵約 0.5 秒（或觸控長按）影片，選「從稍後再看移除」。
- **從收藏夾移除**：「觀看紀錄 → 我的收藏」中長按影片，選「從此收藏夾移除」，收藏夾數量會同步更新。

## 注意
- APK 使用與 btr.6 以前相同的金鑰簽署，可直接覆蓋安裝。
- 64 位元版的版本號較大，裝過 64 位元版的電視若要改裝 32 位元版，需先解除安裝。
