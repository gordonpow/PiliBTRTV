# 需求：側邊欄重整、個人頁面、關注直播、設定搜尋

## 目標

使用者回報（2026-11-09）：直播頁的「我的關注」與推薦直播、分區混在一起；個人資料與設定混在同一頁，個人資料太少。改為側邊欄各自獨立的頁面，並讓設定可以搜尋。

## 使用者決定

- 「我的關注」直播獨立成側邊欄一項，直播頁只留推薦與分區。
- 個人頁面內容：基本資料、關注與粉絲、我的投稿、登入／登出。
- 設定頁可搜尋設定項目。
- 側邊欄順序：搜尋、首頁、動態、歷史、直播、關注、個人（頭像）、設定（齒輪）。

## 驗收條件

### 側邊欄

- **AC-1**：側邊欄依序為搜尋、首頁、動態、歷史、直播、關注、個人、設定，每項都能用上下鍵移動、右鍵進入內容、內容最左按左鍵回到該項。
- **AC-2**：原有頁面（搜尋、首頁、動態、歷史、直播）的焦點移動、重新整理、返回鍵行為不變。

### 關注直播

- **AC-3**：「關注」頁顯示已關注且正在開播的主播卡片，按確認鍵進入直播間；沒有開播時顯示「暫無開播的主播」；未登入時顯示請先登入。
- **AC-4**：直播頁不再有「我的關注」分類，第一個分類為「推薦直播」。

### 個人頁面

- **AC-5**：已登入時顯示頭像、暱稱、UID、等級與經驗條、硬幣數、B 幣餘額、大會員狀態與到期日。
- **AC-6**：顯示關注數、粉絲數、動態數；可開啟「關注列表」，列出關注的 UP主（頭像、名稱、簽名），按確認鍵進入 UP主頁面，往下會繼續載入。
- **AC-7**：「我的投稿」開啟自己的 UP主頁面（沿用現有 UP主頁）。
- **AC-8**：有「退出登入」按鈕（需確認）；未登入時個人頁面顯示登入入口，登入成功後各頁重新載入（沿用原本登入流程）。

### 設定

- **AC-9**：設定頁不再顯示個人資料與登入／登出按鈕，只有設定分類與內容。
- **AC-10**：設定頁上方有搜尋框，可用遙控器輸入關鍵字（支援內建鍵盤或系統鍵盤），列出名稱或說明符合的設定項目與所屬分類。
- **AC-11**：選擇搜尋結果後跳到該分類並把焦點放在該設定項目上，可直接調整。
- **AC-12**：搜尋支援繁簡體輸入（例如輸入「弹幕」也能找到「彈幕」相關設定）。

## 不做

- 關注、取消關注 UP主的操作。
- 個人頁面的收藏、歷史（已在歷史頁）。
- 設定項目本身的增減。

## 限制

- 介面文字繁體中文（台灣用語）。
- 與伺服器簡體字串比對的常數保留原文並加註解。
