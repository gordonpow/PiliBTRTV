# 需求：焦點預載、首頁分頁修正、歷史頁收藏與稍後再看

## 目標

1. 焦點停在影片卡片 0.3 秒就預先準備播放資料，進入播放頁更快開播。
2. 修正首頁所有分類往下捲只有兩列、不再載入新影片。
3. 歷史頁新增「我的收藏」「稍後再看」分頁。

## 使用者決定（2026-11-09）

- 預載程度：API（影片資訊、cid、播放網址、彈幕）＋影片與音訊開頭約 2MB 放快取。
- 收藏：先選收藏夾再看影片（預設收藏夾在最前面）。
- 歷史頁分頁：觀看歷史、我的收藏、稍後再看。

## 驗收條件

### 焦點預載

- **AC-1**：焦點停在影片卡片滿 0.3 秒，背景預抓影片資訊、播放網址、彈幕，並預下載影片與音訊開頭約 2MB；未滿 0.3 秒離開不發請求。
- **AC-2**：預載完成後按確認鍵進入播放頁，播放器使用預載結果，不再重抓同樣的 API（log 可確認），開播時間明顯縮短。
- **AC-3**：預載失敗或過期時，播放器照原流程重抓，播放正常。
- **AC-4**：同一時間只進行一個預載；焦點移到別張卡片時取消舊的預載。預載不建立播放器、不占用解碼器。
- **AC-5**：關閉「播放加速」時只預抓 API，不預下載影片資料，播放正常。

### 首頁分頁

- **AC-6**：首頁每個分類（推薦、熱門、番劇、各分區）往下移動焦點時會持續載入更多影片，不會停在兩列。
- **AC-7**：載入失敗時不卡死，再往下移動會重試。
- **AC-8**：最後一列不滿四張時，從上一列按下鍵可移到最後一列。

### 歷史頁分頁

- **AC-9**：歷史頁上方有「觀看歷史」「我的收藏」「稍後再看」三個分頁，用左右鍵切換、按下鍵進入內容；內容第一列按上鍵回到分頁列。
- **AC-10**：「我的收藏」列出使用者所有收藏夾（預設收藏夾在最前），選擇收藏夾後顯示其影片卡片，往下捲會繼續載入。
- **AC-11**：「稍後再看」顯示稍後再看清單的影片卡片。
- **AC-12**：三個分頁的影片卡片按確認鍵可播放，也有焦點預覽與預載。
- **AC-13**：未登入時三個分頁都顯示「請先登入」；清單為空時顯示空狀態文字。
- **AC-14**：原本觀看歷史的行為（靜默更新、載入更多）不變。

## 不做

- 收藏、取消收藏、稍後再看的新增或刪除操作。
- 預載建立播放器（避免占用解碼器）。
- 首頁自動定時刷新。

## 限制

- 介面文字繁體中文。
- 預載要考慮 B 站風控（-352）：同一影片短期內不重抓。
- 電視記憶體有限：預下載的影片資料最多保留 2 支影片。
