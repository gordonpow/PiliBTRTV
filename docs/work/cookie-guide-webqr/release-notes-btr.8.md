Android TV 版第三方 B站用戶端，基於 BiliTV，加上「線程撕裂者」（BTR）多 CDN 播放加速。

本版包含原訂 btr.7 的全部內容（btr.7 未單獨發布）。

## 下載哪一個？
- `PiliBTRTV-v1.2.2-btr.8-arm64-v8a.apk`：64 位元，大多數較新的電視盒／電視。
- `PiliBTRTV-v1.2.2-btr.8-armeabi-v7a.apk`：32 位元，較舊或 32 位元系統的電視（64 位元版無法安裝時用這個）。
- 從 App 內更新會自動選擇符合裝置的版本。

## 新增
- **網頁版掃碼登入**：TV 掃碼或手機登入出現「当前账号暂不支持在本APP登录」（48007）的帳號，可在登入頁按「改用網頁版掃碼」，用 B 站手機 App 掃描並在手機上確認即可登入。此方式不支援投幣。TV 掃碼遇到 48007 時會直接提示改用網頁版。
- **影片卡片預覽**：焦點移到影片卡片就開始靜音預覽；長按方向鍵快速移動時，停住後才預覽最後一張。可在「設定 → 介面」關閉。
- **更快開播**：預覽開始後按 OK 幾乎立即播放；並縮短起播緩衝、自動改連速度最快的 CDN 主機。
- **播完倒數連播**：「設定 → 播放」新增「播放完畢後」（播完暫停、順序播放、單個循環、列表循環、自動連播）與「連播倒數」（預設 5 秒）。倒數時右下角顯示下一部影片：OK 立即播放、返回取消、下鍵看相關影片。
- **播放中下鍵看相關影片**：控制列顯示時按下鍵直接開「更多影片」。
- **新側邊欄**：搜尋、首頁、動態、直播、歷史、個人、設定；直播頁第一個分類為「關注」。
- **個人頁**：基本資料、關注／粉絲、我的投稿、登入登出。
- **歷史頁**：新增「我的收藏」「稍後再看」分頁與「重新整理」按鈕。
- **設定搜尋**、**回報紀錄**（設定 → 關於）。

## 修正
- 部分電視盒播放影片時閃退（裝置無法解碼影片畫面時）。
- 登入頁按鈕列用方向鍵左右移動時跳錯按鈕、最左邊按左鍵跳到「設定」。
- 手機登入的密碼／簡訊登入遇到 48007 時，改為提示使用網頁版掃碼或 Cookie 登入。
- 手機登入網址第一次開啟後有效時間延長為 45 分鐘。
- 首頁分區往下只載入兩列。
- 設定頁焦點跳錯位置、選不到上方分類列。
- 觀看歷史不顯示最新紀錄。

## 調整
- 開播前的載入圈圈改為顯示在畫面正中間。

## 注意
- APK 使用 debug 金鑰簽署（沿用先前版本），可直接覆蓋安裝。
- 64 位元版的版本號較大，裝過 64 位元版的電視若要改裝 32 位元版，需先解除安裝。
- 修正閃退後，若裝置仍無法解碼某支影片，會只有聲音、沒有畫面；可在設定把首選編碼改為 H.264（AVC）。
- 本版尚未完整實機測試。遇到問題請用「回報問題」回報，並附上回報編號。
