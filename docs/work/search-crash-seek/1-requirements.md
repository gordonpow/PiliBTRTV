# 需求：搜尋鍵盤殘留、閃退回報、Netflix 式縮圖列

日期：2026-11-08　使用者回報（實機電視）

## 目標

修正搜尋後進入影片容易當機的問題，讓閃退後可以一鍵回報，並把快退快進預覽改成 Netflix 式橫向縮圖列。

## 驗收條件

### A. 搜尋後系統鍵盤殘留

- **AC-A1**：用系統鍵盤（IME）輸入並按鍵盤上的「搜尋」後，系統鍵盤關閉，畫面下方不再有鍵盤或空白區。
- **AC-A2**：從搜尋結果點進影片時，系統鍵盤不會出現，播放畫面為全螢幕（不被鍵盤擠壓）。
- **AC-A3**：從播放器返回搜尋結果、再回到搜尋鍵盤頁時，可以再次開啟系統鍵盤輸入（狀態有重置）。
- **AC-A4**：用 App 內建鍵盤搜尋的流程不受影響。

### B. 閃退後詢問是否上傳錯誤報告

- **AC-B1**：App 上一次執行時閃退（Java/Kotlin 例外、原生崩潰、ANR）後，下次啟動進入首頁時跳出對話框「上次 App 異常結束，是否上傳錯誤報告？」。
- **AC-B2**：對話框預設焦點在「取消」；選「上傳」走既有的去識別化錯誤報告流程（預覽 → 上傳 → 顯示網址）。
- **AC-B3**：報告內容包含閃退原因、時間與可取得的堆疊／描述，並經過既有 `sanitizeLogLine` 去識別化。
- **AC-B4**：同一次閃退只詢問一次（取消或上傳後不再出現）；正常關閉或被系統回收記憶體不詢問。

### C. Netflix 式縮圖列

- **AC-C1**：控制列隱藏時按左／右鍵，畫面下方出現橫向縮圖列：正中間是目前選中的縮圖（較大、白色外框），左右各顯示前後的縮圖（超出畫面的部分被裁切）。下方是進度條、目前預覽時間與總長。
- **AC-C2**：每按一次左／右鍵切換到上一張／下一張縮圖，預覽時間跟著改變；按住可以連續切換。
- **AC-C3**：中間縮圖顯示的畫面對應預覽時間（不是錯位的前一幀）。
- **AC-C4**：縮圖畫質比現在清楚（見規格的畫質來源）。
- **AC-C5**：按確認鍵或停止操作 1.5 秒後跳到選中的時間；返回鍵取消並回到原位置（沿用既有行為）。
- **AC-C6**：沒有縮圖資料時，仍顯示進度條與時間，可以正常快退快進。

## 不做的範圍

- 不改控制列顯示時的進度條拖曳行為。
- 不改 App 內建鍵盤的版面。
- 閃退報告不自動上傳，一定要使用者同意。

## 限制

- Android TV，minSdk 依 Flutter 預設；`ApplicationExitInfo` 只在 API 30 以上可用，較舊系統只偵測 Java/Kotlin 例外。
- 介面文字用繁體中文（台灣用語），經過 ZhConvert 的繁簡切換。
- 使用者已說明需求，直接進入規格（未另行確認 AC）。
