Android TV 版第三方 B站用戶端，基於 BiliTV，加上「線程撕裂者」（BTR）多 CDN 播放加速。

## 下載哪一個？
- `PiliBTRTV-v1.2.2-btr.9-arm64-v8a.apk`：64 位元，大多數較新的電視盒／電視。
- `PiliBTRTV-v1.2.2-btr.9-armeabi-v7a.apk`：32 位元，較舊或 32 位元系統的電視（64 位元版無法安裝時用這個）。
- 從 App 內更新會自動選擇符合裝置的版本。

## 新增
- **回報處理狀態**：「設定 → 關於軟體 → 回報紀錄」中，開發者處理過的回報會顯示「已解決」「處理中」或「無法重現」標籤與一句說明，不用另外聯絡就能知道回報的結果。

## 修正
- 從側邊欄「個人」按右鍵進入登入頁時，焦點改落在最左邊的「改用網頁版掃碼」。

## 注意
- APK 使用與 btr.6 以前相同的金鑰簽署，可直接覆蓋安裝。
- 2026-11-09 22:50 前下載的 btr.8／btr.9 簽章錯誤（換電腦建置），在舊版上會顯示「未安裝應用程式」；本頁檔案已更換為正確簽章，請重新下載。若已安裝簽章錯誤的 btr.8／btr.9，需先解除安裝再安裝本版。
- 64 位元版的版本號較大，裝過 64 位元版的電視若要改裝 32 位元版，需先解除安裝。
- 回報狀態需要連上 GitHub（raw.githubusercontent.com）；連不上時沿用上次取得的狀態。
