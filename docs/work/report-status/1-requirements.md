# 需求：回報紀錄顯示處理狀態

日期：2026-11-09　狀態：已確認（使用者選三種狀態、只在回報紀錄顯示）

## 目標

使用者用「回報問題」送出錯誤報告後，開發者修好或確認處理中時，讓該使用者在 App 的回報紀錄看到這筆回報的處理狀態，不用另外聯絡。

## 驗收條件

- **AC-1**：開發者在 repo 的狀態檔把某回報編號標為「已解決」，使用者打開「設定 → 關於 → 回報紀錄」，該筆顯示綠色「已解決」標籤。
- **AC-2**：狀態也可標為「處理中」（橘色）或「無法重現」（灰色），各自顯示對應標籤。
- **AC-3**：狀態可附一句說明（例如「已在 v1.2.2-btr.8 修正，請更新」），顯示在該筆的時間與分類下方。
- **AC-4**：狀態檔沒有該編號時，該筆不顯示標籤，與現在相同。
- **AC-5**：狀態檔更新後不需發布新版 App，使用者下次打開回報紀錄即看到（GitHub raw 快取最多約 5 分鐘）。
- **AC-6**：網路失敗時沿用上次成功取得的狀態；從未成功取得則不顯示標籤；都不跳錯誤訊息。狀態檔格式錯誤時忽略。
- **AC-7**：回報紀錄對話框打開不因下載而延遲：先顯示紀錄，狀態取得後再補上標籤；遙控器操作與現在相同。

## 不做的範圍

- 啟動時主動提示、推播通知。
- 使用者回覆或留言。
- 開發者管理介面（狀態檔由開發者／Claude 直接編輯並推送）。

## 限制

- 狀態檔公開於 GitHub；只放隨機回報編號、狀態、說明，不放任何使用者資料。
- 說明文字用繁體中文（台灣用語）。
