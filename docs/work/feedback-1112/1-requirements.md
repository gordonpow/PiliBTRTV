# 需求：2026-11-12 使用者回饋（登入失效、設定選單、直播控制）

## 目標

修正回報 `report-B6V5DQ.txt` 的登入失效問題，並讓設定頁、彈幕設定面板與直播播放器的遙控器操作一致：左鍵永遠往外／往左移動，選值改用次級選單彈窗。

## 背景（調查結果）

- 報告：19:46 起 `nav`、動態、歷史、關注直播全部回 `-101 账号未登录`，報告仍顯示「已登入: 是」。App 只看本地 `SESSDATA` 是否存在，伺服器端失效時不偵測、不刷新、不提示。`AuthService.logout()` 沒清 `isVip`，登出後仍誤判大會員。
- 直播彈幕就是直播間聊天留言（同一個 `DANMU_MSG`），沒有另外的「留言」。
- 直播沒有走 BTR；用舊 v1 `playUrl`，幾乎只拿到單一 FLV。

## 驗收條件

### 登入失效（報告）
- AC-1：啟動時若 `nav` 回 `-101`，且有 TV 登入的 `access_token`／`refresh_token`，App 呼叫 oauth2 refresh；成功則儲存新的 token 與 Cookie，之後的 API 不再回 `-101`。
- AC-2：refresh 失敗，或是 Cookie 登入（沒有 refresh_token），App 清除本地登入狀態（含 `isVip`），並顯示 toast「登入已失效，請重新登入」。設定摘要的「已登入」顯示「否」。
- AC-3：`logout()` 會清除 `isVip`。
- AC-4：網路錯誤（非 `-101`）不會清除登入狀態。

### 設定頁（項目 2）
- AC-5：設定頁所有原本用左右鍵切換值的選項（播放完畢後、連播倒數、播放畫面模式、影片解碼器、CDN 模式、執行緒數、檢查間隔），按 OK 開啟次級選單彈窗選值，與「語言」相同。
- AC-6：游標在這些選項上按左鍵，焦點跳到左側導覽列。

### 彈幕設定面板（項目 4，直播與一般影片）
- AC-7：在彈幕設定面板按左鍵：由長按彈幕鍵直接開啟時關閉面板；由設定主選單進入時回到主選單。直播一律關閉面板。
- AC-8：在數值項目（透明度、字型大小、佔屏比、速度等）按 OK 或右鍵，開啟次級選單彈窗列出可選值，選定後套用；開關項目按 OK 切換。

### 直播播放器（項目 3、5、6、7）
- AC-9：直播控制列按鈕依序為：播放/暫停、彈幕、留言、畫質、線路、關注。沒有「重新整理」與「彈幕設定」按鈕。
- AC-10：彈幕按鈕短按切換彈幕開關；長按（500ms）直接開啟彈幕設定面板，與一般影片相同。
- AC-11：播放/暫停按鈕與遙控器播放/暫停鍵可以暫停與繼續。繼續時重新連線到最新的直播畫面。
- AC-12：播放器出錯，或緩衝卡住超過 10 秒，App 自動重新連線（退避重試）；彈幕連線中斷也自動重連。重連時不重複訂閱彈幕（彈幕不重複出現）。
- AC-13：「留言」按鈕切換右側聊天列表，顯示「使用者名稱: 內容」，保留最近 100 則並自動捲到最新。預設關閉，使用者開關狀態會記住。

## 不做的範圍

- 直播不接 BTR，不改 v2 `getRoomPlayInfo`（另開 issue 追蹤）。
- 不做發送彈幕。
- 不處理 SUPER_CHAT、禮物訊息。
