# 控制列：點讚／投幣／收藏直接顯示（精簡版）

使用者請求（2026-11-10，附截圖 img/螢幕擷取畫面 2026-11-10 175223.jpg）：

- 把控制列右下角的「在看人數」和「畫質」移到右上角。
- 刪除彈幕數量。
- 點讚、投幣、收藏直接顯示在右下角；收藏的圖示是星星。

## 驗收條件

- AC-1 控制列底排左側依序是：上一部、播放/暫停、下一部、選集、UP主、彈幕、設定。右側（靠右對齊）依序是：點讚、投幣、收藏。
  - 點讚：圖示 `thumb_up_outlined`；已點讚時改成實心 `thumb_up`，並使用強調色。
  - 投幣：圖示 `monetization_on_outlined`；已投幣時改成實心。
  - 收藏：圖示 `star_border`；已收藏時改成實心 `star`。
  - 原本的「👍」按鈕，以及按下後彈出的小面板（`showActionButtons`，player_screen.dart:243 一帶）都移除。
- AC-2 左右鍵可以在 10 顆按鈕之間連續移動，從「設定」按右鍵會到「點讚」。變暗按鈕的跳過規則不變。
- AC-3 按下點讚、投幣、收藏的行為，和原本 `ActionButtons` 小面板中的對應項目相同：
  - 點讚：切換。
  - 投幣：沿用原本的投幣流程與上限。
  - 收藏：沿用原本的收藏流程。
  - 成功或失敗的提示不變。
- AC-4 右上角時間（09:52）的下方，顯示一行「在看:N · 畫質」，例如「在看:2 · 高清 1080P (H.265)」。沒有在看人數時只顯示畫質。字級、透明度與原本相同。只在控制列顯示時出現。
- AC-5 右下角不再顯示彈幕數量，也不再顯示「彈幕／彈幕關」文字。彈幕的開關狀態由彈幕按鈕的圖示表示。

## 做法

- 在 `player_state_mixin.dart` 的 `CtrlBtn` 中，把 `actions` 改成 `like = 7`、`coin = 8`、`fav = 9`，並將 `count` 改成 10。用 grep 找出所有 `CtrlBtn.actions` 和 `count`，一起改。
- 把 `action_buttons.dart` 中點讚、投幣、收藏的狀態載入與動作，抽成可以重用的形式，讓 ControlsOverlay 的三顆按鈕使用。可以是 mixin、controller（ChangeNotifier）或 service，由實作者選擇。不再使用的 widget 程式碼要刪除。
- 在 `controls_overlay.dart` 的 `Spacer` 之後放三顆按鈕，刪除線上人數、彈幕數、畫質的文字；`_formatDanmakuCount` 如果不再使用，也一起刪除。
- 右上角的時間在 `controls_overlay.dart` 的上方區塊（用 grep 找時鐘）。在它的下方加一行在看人數與畫質。
- 返回鍵處理中的 `showActionButtons` 分支（player_event_mixin.dart:275-284）一併移除。

## 使用者補充（2026-11-10）

「不用再多一級菜單」。收藏改成直接切換，不打開選擇收藏夾的選單：

- 還沒收藏：加入預設收藏夾。
- 已收藏：從所在的收藏夾全部移除。

投幣因為不能撤銷，保留原本的確認流程。
