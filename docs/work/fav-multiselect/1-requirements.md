# 需求：影片收藏選單、觀看紀錄多選

使用者 2026-11-10 要求，選項已確認（卡片長按＋播放器設定面板都要；選擇收藏夾；多選可刪除、收藏、稍後再看）。

## 目標

讓使用者不用進播放頁就能收藏影片並選收藏夾；觀看紀錄可以一次處理多部影片。

## 驗收條件

- AC-1 影片卡片長按 OK（遙控器確定鍵長按約 0.5 秒以上，觸控長按亦可）跳出「影片選項」：收藏、稍後再看、取消。適用首頁各分頁、搜尋結果、動態、觀看歷史（非多選模式時見 AC-5）、我的收藏、稍後再看、UP 主頁等所有影片卡片；番劇／直播卡片不顯示收藏（或該選單只列可用項目）。短按行為不變（播放）。
- AC-2 選「收藏」跳出收藏夾清單（使用者建立的收藏夾，含預設收藏夾），每列有勾選框，已含此影片的收藏夾預先勾選；方向鍵移動、OK 切換勾選，下方「確定」「取消」。確定後依差異加入／移出，提示「已收藏到 N 個收藏夾」或「已取消收藏」；失敗顯示錯誤訊息。
- AC-3 播放器設定面板新增「收藏」項目，開啟與 AC-2 相同的收藏夾選擇；播放器既有收藏按鈕行為不變。
- AC-4 選「稍後再看」加入稍後再看，提示「已加入稍後再看」（已存在時提示「已在稍後再看」）。
- AC-5 觀看歷史：長按 OK 進入多選模式，被長按的那部先勾選；畫面上方顯示「已選 N 部」與按鈕列：全選、刪除、加入收藏、稍後再看、取消。多選模式中短按 OK 切換勾選（不播放），返回鍵 = 取消多選。
- AC-6 多選「刪除」：先確認對話框「刪除 N 筆觀看紀錄？」，確定後從 B 站帳號刪除並從列表移除；部分失敗時提示失敗筆數。
- AC-7 多選「加入收藏」：開收藏夾選擇（不預先勾選），確定後把所選影片加入勾選的收藏夾；「稍後再看」：全部加入。完成後提示成功／失敗筆數並離開多選。
- AC-8 未登入時選單項目提示「請先登入」。
- AC-9 焦點：選單、收藏夾清單、多選按鈕列都能完全用方向鍵操作，關閉後焦點回到原本的卡片。

## 不做

- 新增／改名收藏夾。
- 我的收藏、稍後再看分頁的多選（只做觀看歷史）。

## 限制

- 介面文字繁體中文；log 不含 Cookie、csrf。
- 不影響播放效能相關改動（同一工作樹內尚未 commit 的 playback-diag 改動）。
