# 需求：未登入時的本機收藏（#20）

## 目標
未登入的使用者也能收藏影片；登入後可匯入帳號。

## 驗收條件
- AC-1：未登入時按控制列☆或設定面板「收藏」，開啟本機收藏夾選單（與帳號收藏夾選單相同的操作：勾選多個、已收藏打勾），套用後 toast 列出資料夾名稱，星星同步。不再要求登入。
- AC-2：本機收藏夾可建立、重新命名、刪除；預設有一個「本機收藏」（不可刪除，可重新命名）。選單內可直接「新增收藏夾」。
- AC-3：未登入時，觀看歷史的「收藏」分頁顯示本機收藏夾清單與各夾影片（格狀卡片，與帳號收藏相同樣式），可播放、取消收藏、管理資料夾（重新命名、刪除）。
- AC-4：本機收藏存影片的 bvid、aid、標題、封面、UP 主名稱、時長、加入時間；播放時以 bvid 開啟。資料存在本機（SharedPreferences 或 app documents JSON），重新啟動後保留。
- AC-5：登入成功後若本機收藏有影片，跳出「要把 N 部本機收藏加入帳號的預設收藏夾嗎？」：
  - 是：逐筆加入帳號預設收藏夾（已在其中的略過），完成後 toast 結果並清空本機收藏；部分失敗時保留失敗的項目並提示。
  - 否：保留本機收藏，下次登入不再自動詢問；「收藏」分頁在已登入時另外列出「本機收藏」區塊可手動匯入。
- AC-6：已登入時，☆與設定面板「收藏」維持現在的帳號收藏夾行為。
- AC-7：登出後回到本機收藏模式，本機資料不受登入期間影響。
- AC-8：`flutter analyze` 無問題、測試通過；新介面字串補進 `i18n/en.json`。

## 不做
- 本機收藏與帳號雙向同步。
- 匯入到預設以外的帳號收藏夾（之後可再加）。
