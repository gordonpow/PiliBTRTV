# 需求：UP主主頁改為全螢幕格狀頁面

日期：2026-11-09

## 目標

使用者回報：播放器中的 UP主面板（右側 400px 窄列表，`lib/screens/player/widgets/up_panel.dart`）不夠直觀。希望改成像首頁、搜尋結果那樣的格狀卡片，顯示更多資訊。

## 使用者決定（2026-11-09）

- 開啟方式：全螢幕新頁面。開啟時暫停影片，按返回鍵回到播放器並繼續播放。
- 資訊區：頭像、名稱、簽名、粉絲數、投稿數，保留「最新／最熱」排序與關注按鈕。

## 驗收條件

- **AC-1**：在播放器控制列按「UP主」，開啟全螢幕 UP主頁面，影片暫停。
- **AC-2**：頁面上方顯示頭像、名稱、簽名、粉絲數、投稿數，以及「最新／最熱」排序按鈕與關注按鈕（可用遙控器操作，行為與舊面板相同）。
- **AC-3**：下方以每列 4 個卡片顯示投稿影片。卡片包含封面、播放數、彈幕數、時長、標題、UP主名稱與發布日期。
- **AC-4**：捲到接近底部時自動載入下一頁，直到沒有更多影片。
- **AC-5**：遙控器上下左右可在卡片間移動；在第一列按上鍵會移到排序按鈕；在按鈕列按下鍵回到第一張卡片。
- **AC-6**：選擇影片後關閉 UP主頁面，播放器改播該影片（與舊面板行為相同）。
- **AC-7**：在 UP主頁面按返回鍵，回到播放器；原本在播放的影片繼續播放，原本暫停的影片維持暫停。
- **AC-8**：UP主資訊 API 失敗時，資訊區退回只顯示播放器已知的名稱與頭像，影片列表仍可使用。
- **AC-9**：`flutter analyze` 沒有新增問題，可以建置。

## 不做的範圍

- 從播放器以外的地方（首頁卡片、動態、搜尋）進入 UP主頁面。
- 動態、合集、專欄等其他分頁。
- 首頁、搜尋等其他列表的卡片外觀不變（彈幕數只在 UP主頁面顯示）。

## 限制

- Android TV 遙控器操作。
- 介面文字使用繁體中文（台灣用語）；伺服器回傳的簽名等內容依現有 ZhConvert 規則顯示。

## 第二階段：主頁／動態／投稿分頁（2026-11-09）

使用者要求：UP主頁面要有「主頁、動態、投稿」分頁，與 PiliBTR 相同。

### 使用者決定

- 動態：只顯示影片動態（含轉發的影片），卡片格狀、可播放。
- 投稿：子分頁「影片」（最新／最多播放排序）與「合集／系列」（選取後顯示該合集的影片）。圖文、音訊、漫畫不做。
- 主頁：影片類區塊——最新影片、合集／系列、最近投幣、最近點讚、追番。每個區塊一列可左右移動的卡片，可按「更多」。

### 已確認的事實（curl，未登入）

- `app.bilibili.com/x/v2/space`（appkey 簽名，專案已有 `AppSign`）回傳 `card`、`tab2`、`default_tab`、`archive`、`series`、`ugc_season`、`season`（追番）、`coin_archive`、`like_archive`。
- `x/v2/space/archive/cursor`、`x/v2/space/season/videos`、`x/v2/space/series` 都回 `code 0`，項目欄位：`title`、`cover`、`param`（aid）、`bvid`、`duration`、`play`、`danmaku`、`ctime`、`author`、`first_cid`。

### 新增驗收條件

- **AC-10**：資訊區下方有分頁列「主頁｜動態｜投稿」。分頁依 `tab2` 顯示（只保留 home、dynamic、contribute，`tab2` 沒有的不顯示）；初始分頁依 `default_tab`（`video` 對應投稿），API 失敗時固定顯示三個分頁、預設投稿。
- **AC-11**：主頁分頁依序顯示有資料的區塊：最新影片、合集、系列、最近投幣、最近點讚、追番。每個區塊一列橫向卡片，區塊最後一張是「更多」：最新影片 → 切到投稿的影片；合集／系列 → 切到投稿的合集／系列並開啟該合集；投幣／點讚／追番 → 不顯示「更多」。
- **AC-12**：動態分頁以 4 欄卡片顯示影片動態（含轉發中的影片），捲到底依 `offset` 載入下一頁。
- **AC-13**：投稿分頁有子分頁「影片」「合集／系列」（UP主沒有合集與系列時不顯示後者）。影片可切換「最新／最多播放」，捲到底載入更多。合集／系列先列出合集卡片，選取後顯示該合集的影片，返回鍵回到合集列表。
- **AC-14**：選取追番卡片時以番劇模式播放。
- **AC-15**：所有影片卡片選取後的行為與第一階段相同（關閉 UP主頁面、播放器改播該影片）。
- **AC-16**：遙控器：分頁列左右切換分頁；從分頁列按下鍵進入內容；內容最上方按上鍵回到分頁列；資訊區的關注按鈕可從分頁列按上鍵到達。返回鍵在合集影片中先回到合集列表，其他情況關閉 UP主頁面。

### 第二階段不做

- 動態中的圖文、純文字、直播等非影片動態。
- 投稿中的圖文、音訊、漫畫、充電專屬子分頁。
- 收藏、追番以外的其他頂層分頁（收藏、課程、商店）。
