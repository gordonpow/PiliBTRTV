# 需求：播放時查看影片簡介與留言（#39）

## 目標
觀眾播放影片時，不離開播放器就能看影片簡介與留言。

## 驗收條件
- AC-1：控制列「設定」右邊有「簡介」按鈕；按確認鍵開啟右側資訊面板，影片繼續播放。
- AC-2：面板有「簡介」「留言」兩個分頁，左右鍵切換。
- AC-3：簡介分頁顯示標題、UP 主、發布日期、播放／彈幕／讚／幣／收藏／留言數與完整簡介；上下鍵捲動。番劇或沒有簡介時顯示「沒有簡介」。
- AC-4：留言分頁依熱門排序顯示留言（置頂留言在最前）：暱稱、時間、讚數、內容、回覆數；上下鍵逐則移動，接近底部自動載入下一頁；沒有更多時顯示「沒有更多留言」。
- AC-5：載入中、失敗（顯示錯誤並可按確認鍵重試）、沒有留言時各有提示。
- AC-6：返回鍵關閉面板，焦點回到控制列的「簡介」按鈕。
- AC-7：簡介與留言內容使用 ContentText（依語言設定做繁簡轉換、英文翻譯；#38 原文模式不轉換）。
- AC-8：換集或換影片時，面板關閉並清除已載入的留言。

## 不做
- 查看樓中樓回覆、發表或按讚留言、表情圖片（[doge] 以文字顯示）、留言排序切換。

## 限制
- 未登入時 B 站只回傳少量留言，照 API 結果顯示。
- 介面文字只用繁體中文；新增字串要加入 i18n/en.json。
- 不可修改 auth_api.dart、live_api.dart、btr_config.dart、app_restart.dart。
