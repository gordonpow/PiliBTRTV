Android TV 版第三方 B站用戶端，基於 BiliTV，加上「線程撕裂者」（BTR）多 CDN 播放加速。
An unofficial third-party Bilibili client for Android TV with BTR multi-CDN acceleration.

## 下載哪一個？ / Which APK?
- `PiliBTRTV-v1.2.2-btr.21-arm64-v8a.apk`：64 位元，大多數較新的電視盒和電視用這個。Most modern TVs and boxes.
- `PiliBTRTV-v1.2.2-btr.21-armeabi-v7a.apk`：32 位元，64 位元版裝不上時改用這個。Older 32-bit systems.
- 從 App 內更新或 F-Droid 套件庫更新時，會自動選擇符合裝置的版本。In-app update and the F-Droid repo pick the right one automatically.

## 新增
- **播放時查看簡介與留言**（#39）：播放時叫出控制列，選「設定」右邊的「簡介」按鈕，右側會打開面板，影片繼續播放。左右鍵切換「簡介」與「留言」，上下鍵捲動；留言依熱門排序，置頂留言排最前，捲到底部自動載入更多。返回鍵關閉面板。目前不支援查看樓中樓回覆與發表留言。
- **「原文」語言選項**（#38）：「設定 → 介面 → 語言」新增「原文（不轉換）」。介面維持繁體，影片標題、留言、彈幕、字幕照上傳者原文顯示，不做繁簡轉換。重新啟動後生效。

## New
- **Description and comments while playing**: open the controls and pick the new "Description" button next to Settings. Use left/right to switch between Description and Comments; comments load more as you scroll. Press Back to close.
- **"Original" language option**: shows titles, comments, danmaku and subtitles exactly as uploaded, without Traditional/Simplified conversion. The interface stays in Traditional Chinese.

## 注意
- APK 使用與之前相同的金鑰簽署，可以直接覆蓋安裝。
- 64 位元版的版本號比較大。電視裝過 64 位元版之後，若要改裝 32 位元版，要先解除安裝。
