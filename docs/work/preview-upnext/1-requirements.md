# 需求：即時卡片預覽、播放中下鍵看相關影片、播完倒數連播

使用者請求（2026-11-09）：

1. 焦點停 1 秒才預覽還是太久，要選到卡片就馬上預覽；但長按方向鍵快速移動時不能每張都預覽（負擔太大）。
2. 播放中按 OK 或下鍵顯示控制列後，再按下鍵直接顯示相關影片。
3. 影片播完倒數（預設 5 秒）後播下一部，秒數與播放完畢模式可調整（模式同 PiliBTR），並顯示待播影片卡片；使用者往下按看相關影片時停止倒數。

使用者要求直接做，驗收條件未經使用者逐條確認。

## 驗收條件

- **AC-1**：單次按方向鍵把焦點移到影片卡片後，約 0.15 秒內開始準備預覽（不再等 1 秒）。
- **AC-2**：長按方向鍵連續移動時，經過的卡片不開始預覽／暖機；放開按鍵、焦點停住約 0.25 秒後，只有最後一張開始預覽。
- **AC-3**：快速連按（兩次移動間隔小於 0.3 秒）時，同 AC-2，只在停住後才預覽。
- **AC-4**：播放中控制列顯示時按下鍵，開啟「更多影片」（相關影片）面板；控制列隱藏時按 OK 或下鍵仍是顯示控制列。
- **AC-5**：播放設定新增「播放完畢後」：播完暫停、順序播放、單個循環、列表循環、自動連播（預設自動連播）。舊設定「自動連播」關閉的使用者，升級後為「播完暫停」。
- **AC-6**：播放設定新增「連播倒數」：0（立即播放）、3、5、10、15 秒，預設 5 秒。
- **AC-7**：播完要播下一部（下一集或推薦影片）且倒數大於 0 時，右下角顯示「接下來播放」卡片（封面、標題、剩餘秒數），倒數結束自動播放。
- **AC-8**：倒數中按 OK 立即播放；按返回取消倒數並顯示控制列；按下鍵取消倒數並開啟相關影片面板；按左右鍵取消倒數並照常快退快進。
- **AC-9**：各模式行為：播完暫停＝停住；順序播放＝有下一集播下一集，否則停住；單個循環＝從頭重播（不倒數）；列表循環＝下一集，最後一集回到第一集，單一影片則重播；自動連播＝下一集，沒有就播第一個推薦影片（番劇最後一集停住）。
- **AC-10**：試看片段、UP主頁面開啟中，維持原本不連播的行為。設定搜尋找得到兩個新設定。

## 不做

- 不改暖機播放器（instant-play）的接手邏輯。
- 倒數卡片不做「取消」「立即播放」按鈕焦點，只用按鍵提示。

## 限制

- 只用繁體中文；`flutter analyze` 無問題、既有測試通過。
